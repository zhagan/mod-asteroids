# mod-asteroids

**Asteroids**, rebuilt in **React**, with **procedural WebAudio** powered by **[@mode-7/mod](https://github.com/mode7labs/mod)**.

This project is equal parts:
- a playable Asteroids-style game
- a reference implementation for wiring procedural sound + real-time UI in a React app
